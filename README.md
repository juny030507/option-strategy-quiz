# 옵션 투자기법 퀴즈 게임

[![Python 3.10 unit tests](https://github.com/juny030507/option-strategy-quiz/actions/workflows/tests.yml/badge.svg)](https://github.com/juny030507/option-strategy-quiz/actions/workflows/tests.yml)

옵션 투자 전략과 헤지 개념을 객관식 문제로 복습하는 Python 콘솔 퀴즈
게임입니다.

## 프로젝트 목표

Codyssey 입학 연수 과제로 객체지향 설계, 입력 검증, JSON 영속성,
단위 테스트, Git·GitHub 기반 개발 흐름을 한 프로그램에서 연습했습니다.
사용자는 기본 퀴즈를 풀고, 직접 문제를 추가하며, 재실행 후에도
퀴즈와 누적 점수를 이어서 사용할 수 있습니다.

### 옵션 투자기법을 선택한 이유

옵션 전략은 구성 포지션, 시장 전망, 손익 구조가 서로 달라 반복 학습이
필요합니다. 콜·풋 매수, 보호적 풋, 커버드 콜, 펜스, 델타헤지,
포트폴리오 보험을 프로그래밍 결과물로 정리하면서 Python과 금융 개념을
함께 복습하기 위해 이 주제를 선택했습니다.

## 실행 환경과 방법

- Python 3.10 이상
- 외부 라이브러리 없음

저장소를 복제한 뒤 프로젝트 루트에서 실행합니다.

```bash
python3 main.py
```

전체 테스트는 표준 라이브러리 `unittest`로 실행합니다.

```bash
python3 -m unittest discover -s tests -v
```

현재 총 58개의 테스트가 모델, 퀴즈 흐름, 입력 방어, 저장·복구와
`main.py` 통합 흐름을 검증합니다.

## 메뉴와 사용법

| 번호 | 메뉴 | 동작 |
| ---: | --- | --- |
| 1 | 퀴즈 풀기 | 등록된 문제를 차례로 풀고 즉시 채점합니다. |
| 2 | 퀴즈 추가 | 문제, 선택지 4개, 정답 번호를 입력해 사용자 퀴즈를 추가합니다. |
| 3 | 퀴즈 목록 | 기본·사용자 퀴즈의 문제와 선택지를 보여줍니다. |
| 4 | 점수 확인 | 풀이 수, 정답 수, 정답률을 보여줍니다. |
| 5 | 종료 | 현재 상태를 저장하고 종료합니다. |

- 퀴즈 풀이나 추가 중 `0`을 입력하면 현재 답안을 채점하거나 미완성
  퀴즈를 추가하지 않고 메인 메뉴로 돌아갑니다. 앞서 채점된 답안은
  그대로 유지됩니다.
- 빈 입력, 숫자가 아닌 입력, 허용 범위 밖의 번호는 안내 후 다시
  입력받습니다.
- `Ctrl+C`나 EOF로 입력이 끝나면 퀴즈 풀이·추가를 안전하게 취소하고,
  메뉴 입력 중이었다면 현재 상태를 저장한 뒤 프로그램을 종료합니다.

## 퀴즈와 점수

첫 실행 상태에는 10개의 기본 퀴즈가 있습니다. 사용자가 추가한 퀴즈도
동일하게 풀이·목록·저장 대상이 됩니다. 답안을 제출할 때마다 풀이 수가
증가하고, 정답이면 정답 수도 증가합니다. 정답률은
`correct_count / attempt_count * 100`으로 계산하며, 풀이 전에는 0.0%입니다.

## `state.json` 저장과 복구

`state.json`은 실행한 현재 디렉터리가 아니라 `storage.py`가 있는
프로젝트 루트에 저장됩니다.

- 프로그램 시작: 퀴즈 목록과 누적 점수를 불러옵니다.
- 퀴즈 풀이 후: 누적 점수를 저장합니다.
- 퀴즈 추가 후: 사용자 퀴즈를 포함한 목록을 저장합니다.
- 정상 종료 또는 메뉴 입력 중단: 종료 전 현재 상태를 저장합니다.

파일이 없으면 안내 문구를 출력하고 기본 10문제·0점 게임을 생성합니다.
파일 읽기 오류, 손상된 JSON, 누락된 구조, 잘못된 퀴즈나 점수 값도
프로그램을 중단하지 않고 안내 후 기본 게임으로 복구합니다.

```json
{
  "quizzes": [
    {
      "question": "커버드 콜(Covered Call)의 구성으로 옳은 것은?",
      "choices": [
        "기초자산 없이 콜옵션 매도",
        "기초자산 보유 + 풋옵션 매수",
        "기초자산 보유 + 콜옵션 매수",
        "기초자산 보유 + 콜옵션 매도"
      ],
      "answer": 4
    }
  ],
  "score": {
    "correct_count": 0,
    "attempt_count": 0
  }
}
```

제출용 `state.json`은 모든 사용자가 같은 첫 실행 상태에서 시작하도록
개인 검증 데이터를 제거하고 기본 10문제, `correct_count: 0`,
`attempt_count: 0`으로 초기화했습니다. JSON을 손으로 조립하지 않고
`create_default_game()`과 `save_state()`로 재생성했습니다.

| `main.py` | 메뉴, 안전한 입력, 풀이·추가·목록·점수 흐름과 저장 시점을 연결합니다. |

## 테스트와 GitHub Actions

`.github/workflows/tests.yml`은 `main` 대상 push와 pull request에서 실행됩니다.
`ubuntu-latest`, `actions/checkout@v6`, `actions/setup-python@v5`, Python 3.10을
사용하고 `python -m unittest discover -s tests -v`로 58개 테스트를 검증합니다.
워크플로 권한은 `contents: read`로 제한했으며, `main` 브랜치는 PR과
성공한 `Python 3.10 unit tests` 검사를 필수로 합니다.

## 개발 흐름과 학습 내용

기능별 브랜치에서 작은 커밋을 만들고 PR의 diff·테스트를 검토한 뒤
merge commit 방식으로 병합했습니다. PR #6부터는 Draft로 시작해 필수
검사 성공 후 Ready로 전환하는 흐름을 사용했습니다.

| PR 단계 | 기능 흐름 |
| --- | --- |
| #1~#2 | 반복 메인 메뉴, 숫자 입력 검증과 안전 종료 |
| #3~#5 | `Quiz`, 기본 옵션 퀴즈, `QuizGame`과 누적 점수 |
| #6~#7 | 퀴즈 풀이·점수 확인, 사용자 퀴즈 추가·목록 |
| #8 | JSON 저장·복원과 `main.py` 통합 |
| #9 | 퀴즈 풀이·추가 중 `0`으로 메인 메뉴 복귀 |
| #10 | 모델 불변 조건, 방어 테스트, 금융 용어·PEP 8 정리 |

주요 문제와 학습 내용은 다음과 같습니다.

- 입력은 정상 경로만큼 빈 값, 잘못된 타입·범위, 중단 경로를 명시적으로
  설계해야 합니다.
- `unittest` 발견 결과와 실제 실행 개수를 함께 확인해야 빈 또는
  중첩된 테스트를 찾을 수 있습니다.
- JSON 경계에서 타입·범위·관계를 모두 검증하고 예상 가능한 예외만
  처리하면 손상 파일에서도 안전하게 복구할 수 있습니다.
- 모델, 게임 규칙, 파일 입출력, UI 흐름을 분리하면 단위 테스트와
  변경 영향 추적이 쉬워집니다.
- 작은 커밋, Draft PR 검토, CI, 브랜치 보호를 연결하면 로컬 성공을
  원격 병합 규칙으로 유지할 수 있습니다.
